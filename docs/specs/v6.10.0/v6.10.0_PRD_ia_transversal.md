# PRD — v6.10.0 · IA como recurso transversal (fim do menu "Inteligência Logística - IA")

> **Status**: **PRD aprovado** — mapeamento da §5 e nível de versão (§9) decididos. Próxima etapa do processo oficial é o Protótipo Funcional (README_AI.md); nenhum código de UI foi alterado na elaboração deste documento.
> **Módulo afetado**: todo o grupo de menu "Inteligência Logística - IA" (7 telas) é dissolvido; seu conteúdo passa a viver dentro de Diagnóstico Logístico, Benchmark Logístico, Concorrência Logística (BID) e Configuração.
> **Base**: plataforma v6.9.1 (Matriz Benchmark OD como SSoT, ver `docs/11_changelog.md` [6.9.0]/[6.9.1]).
> **Origem**: continuação da consolidação de navegação iniciada nesta mesma leva (categoria 1 — benchmark SSoT, fechada em [6.9.0]; categoria 2 — dedup Recomendações/Oportunidades, fechada nesta versão junto com a remoção de `BenchmarkRecomendacoes.jsx`).

---

## 1. Visão geral

Hoje a IA vive em um menu próprio ("Inteligência Logística - IA", 7 telas: Visão Geral, Diagnóstico IA, Insights, Score Logístico, Oportunidades, Assistente, Base de Conhecimento). Isso contraria o princípio de produto já ratificado (`docs/00_contexto_oficial.md`, Seção 8; `docs/22_plano_diretor_tecnico.md`, Seção 14, Princípio 3): **a IA interpreta, nunca calcula** — e, por extensão de produto, não deveria competir como um "quinto pilar" ao lado de Diagnóstico/Metas/Benchmark/BID, e sim aparecer dentro de cada um deles, no ponto em que o usuário já está olhando o número que ela explica.

Esta versão redesenha a navegação da camada de IA sem alterar nenhum cálculo, endpoint ou regra de negócio (`RN-43` a `RN-55` permanecem exatamente como estão) — é reorganização de onde cada peça aparece, não o que ela calcula.

## 2. Problema de negócio

1. Usuário precisa sair do contexto de "Benchmark" e entrar em outro menu ("IA") para ver *por que* seu percentil está alto — a explicação da IA está desacoplada do dado que ela explica.
2. "Oportunidades" (IA) e "Recomendações" (Diagnóstico) competem pela mesma pergunta do usuário ("o que eu faço agora?") em dois lugares diferentes do menu, com origem de dado diferente — fonte de confusão já identificada nesta consolidação.
3. O Score Logístico é um número que resume os outros 4 módulos (30% Nacional + 20% Regional + 20% Transportadoras + 15% Filiais + 15% Economia, `RN-43`) mas vive isolado em vez de aparecer onde esses módulos são vistos.

## 3. Objetivos da versão

| # | Objetivo | Métrica de sucesso |
|---|---|---|
| OBJ-1 | Cada peça de IA aparece embutida no módulo (Diagnóstico/Benchmark/BID) a que seus dados pertencem | Nenhuma tela nova de "IA" isolada permanece no menu, exceto Base de Conhecimento (§5) |
| OBJ-2 | Nenhum endpoint, cálculo ou regra de negócio muda | `RN-43` a `RN-55` sem alteração; nenhum contrato de API quebrado |
| OBJ-3 | Assistente Logístico deixa de ser destino de menu e vira recurso global (chat flutuante) | Acessível a partir de qualquer tela autenticada |
| OBJ-4 | Visão Geral (`InteligenciaDashboard.jsx`) é absorvida pelo Dashboard geral, sem perda de KPI | Os 4 KPIs hoje exclusivos dela (economia potencial/capturada, oportunidades abertas, insights gerados) aparecem no Dashboard (`/`) |

## 4. Estado atual — as 7 telas do menu "Inteligência Logística - IA"

| Tela | Rota | Endpoint | Dado consumido |
|---|---|---|---|
| Visão Geral | `/inteligencia` | `GET /inteligencia/dashboard` | Economia potencial/capturada, oportunidades abertas, insights gerados |
| Diagnóstico IA | `/inteligencia/diagnostico` | `POST`/`GET /inteligencia/diagnostico` | Narrativa executiva (resumo, pontos fortes/atenção, plano de ação) sobre indicadores de Diagnóstico/DLG |
| Insights | `/inteligencia/insights` | `GET`/`POST /inteligencia/insights` | Alertas de motor de regras (`RN-49`-`51`) sobre Benchmark/concentração/economia |
| Score Logístico | `/inteligencia/score` | `GET /inteligencia/score(+/historico)`, `GET /inteligencia/benchmark-setorial` | Score 0-100 (`RN-43`-`48`) + Benchmark Setorial |
| Oportunidades | `/inteligencia/oportunidades` | `GET`/`POST /inteligencia/oportunidades` | Renegociação/Concentração/Consolidação/BID (`RN-52`-`55`) |
| Assistente | `/inteligencia/assistente` | `POST /inteligencia/assistente/sessoes/.../mensagens` | Chat com tool-calling (10 ferramentas SQL) |
| Base de Conhecimento | `/inteligencia/conhecimento` | `/inteligencia/rag/*` | Documentos indexados (RAG) |

## 5. Decisão por peça — destino proposto

| Peça | É puramente narrativo? | Destino proposto | Como aparece lá |
|---|---|---|---|
| **Score Logístico** | Não — número é 100% determinístico (`RN-43`-`48`); só o rótulo é IA | Dashboard geral (`/`) + Benchmark | Card/badge fixo no topo do Dashboard; dentro de Benchmark, o componente "Benchmark" do score (20%) fica ao lado do comparativo de mercado |
| **Benchmark Setorial** | Comparação determinística com médias por segmento | Dentro de Benchmark Logístico | Painel adicional em `BenchmarkDiagnostico.jsx` ou `BenchmarkComparativoMercado.jsx` |
| **Insights** | Motor de regras determinístico (`RN-49`-`51`); texto é template | Painel de notificações global (sino no `AppBar`) | Clique abre lista; cada insight linka para a tela do módulo a que se refere (ex.: insight de concentração → Benchmark) |
| **Diagnóstico IA** | Narrativa 100% (LLM/simulado) sobre número já calculado | Aba "Resumo executivo" dentro do Dashboard geral | Seção expansível no topo do Dashboard, ao lado dos cards nacionais |
| **Oportunidades** | Regras determinísticas (`RN-52`-`55`) + texto narrativo | Dividido por tipo: Renegociação/Concentração/Consolidação → Benchmark; tipo BID → módulo BID | Painel "Oportunidades" dentro de cada módulo, filtrado pelo tipo pertinente — **substitui de vez** a tela `Oportunidades.jsx` isolada e formaliza a decisão já tomada nesta consolidação de remover `BenchmarkRecomendacoes.jsx` |
| **Assistente Logístico** | Interpretativo (tool-calling sobre SQL real) | Recurso global — botão de chat flutuante, não item de menu | Disponível em qualquer tela autenticada, mantendo contexto da tela atual quando possível |
| **Base de Conhecimento (RAG)** | Não é interpretação de dado operacional — é administração de conteúdo indexado | Configuração | Mantém tela própria, mas migra de grupo de menu ("Inteligência IA" → "Configuração"), já que é gestão, não análise |
| **Visão Geral (`InteligenciaDashboard.jsx`)** | Consolidação de 4 KPIs já cobertos acima | Absorvida pelo Dashboard geral | Tela deixa de existir como destino próprio (OBJ-4) |

## 6. Novo mapa de navegação (proposta)

O grupo "Inteligência Logística - IA" desaparece do menu lateral. Resulta em:

- **Diagnóstico Logístico**: Dashboard (+ Score Logístico, Diagnóstico IA, Insights embutidos), Diagnóstico (DLG), Recomendações, Relatórios.
- **Benchmark Logístico**: Dashboard Executivo, Diagnóstico, Comparativo de Mercado (+ Benchmark Setorial, Oportunidades de Renegociação/Concentração/Consolidação embutidas), Potencial de Economia.
- **Concorrência Logística - BID**: inalterado, + Oportunidades tipo BID embutidas no Dashboard BIDs.
- **Configuração**: ganha "Base de Conhecimento".
- **Global** (fora do menu lateral): botão de chat flutuante (Assistente Logístico), acessível de qualquer tela.

## 7. Componentes novos necessários (não implementados nesta versão — insumo para Especificação Técnica)

- Painel de IA embutível/reutilizável (usado dentro de Dashboard, Benchmark e BID) — recebe `empresa_id` + tipo de conteúdo, chama o endpoint correspondente.
- Sino de notificações (Insights) no `AppBar`, com contador de não-lidos (`PATCH /inteligencia/insights/{id}/lido` já existe).
- Botão/painel de chat flutuante para o Assistente — reaproveita `useIaSessoes`/`useIaMensagens` já existentes, só muda o container visual (de tela cheia para overlay).

## 8. Fora de escopo

- Qualquer mudança de cálculo, prompt de IA, fórmula de score ou regra de insight/oportunidade.
- Migração de modo simulado para IA real — independente desta reorganização.
- Portal do Cliente ou qualquer exposição direta ao cliente final — este PRD trata só da Plataforma do Analista.

## 9. Riscos e pontos de atenção

- **Versionamento — decidido: MINOR (v6.10.0), condicionado.** Dissolver o menu "Inteligência Logística - IA" se encaixaria em "redesenho de módulo" (MAJOR, `docs/00_contexto_oficial.md`, Seção 11) se rotas fossem simplesmente removidas. Decisão: manter MINOR **na condição de que toda rota `/inteligencia/*` hoje existente ganhe redirecionamento de compatibilidade** (`<Navigate replace>`) para seu novo destino, seguindo o mesmo padrão já usado em `App.jsx` para `/benchmark/matriz-od → /inteligencia-mercado/matriz-od`. Isso é requisito de aceite da Especificação Técnica, não opcional — sem os redirects, a mudança reclassifica para MAJOR.
- **Assistente como overlay global**: precisa não conflitar visualmente com o `EmpresaSelector`/`AppBar` já existentes — validar no Protótipo Funcional.
- **Insights linkando para outro módulo**: exige que cada insight carregue metadado suficiente (região/transportadora/tipo) para montar o link de destino — verificar se `dados` (JSON) já cobre isso ou se precisa de campo novo.
